# basalt-plugin-parser-csharp

Tree-sitter C# parser plugin for Basalt.

## Capabilities
- `SYNTAX_PARSER`: Provides syntax highlighting and basic scope extraction.
- `parse.call-sites@csharp/v1`: Extracts function/method call sites.
- `parse.retrieval@csharp/v1`: Extracts semantic retrieval chunks (methods, classes, namespaces).
